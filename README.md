# SightFlow VMS

RTSP 카메라 영상을 FFmpeg로 디코딩해 Qt/QML 화면에 실시간으로 표시하고, 화면
변화를 감지해 이벤트와 스냅샷을 기록·조회하는 C++ 영상관리시스템(VMS)
프로토타입입니다.
